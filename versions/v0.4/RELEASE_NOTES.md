# Command Pop! v0.4 — two-color-theme release checkpoint

Published October 17, 2026, following the original v0.3 launch.

## What changed
- Added pale blue/green **Light mode**, based on the user-selected airy background.
- Added deep blue **Dark mode**, based on the user-selected night background.
- Added a Light/Dark button in the header.
- Theme preference persists locally on the device when browser storage is available.
- Kept blue navigation, green file, and purple search/network bubble families, including the full-color icons.
